Ai-Shell

连上 Linux，用自然语言做运维

桌面端 SSH 运维台：Agent 排查问题，你也可以自己敲命令——高危变更需确认，凭据永不交给模型。

下载安装包 查看源码

同一控制台，两条工作路径

自然语言走 Agent 与工具；像 shell 的一行直接进常驻终端。需要真 TTY 时切到交互终端。

Agent 会话

问一句，排查一整台机

诊断采集、日志与 systemd、状态快照与 diff、变更后校验、文件备份回滚——策略引擎挡住不可逆操作，高危步骤先问你。

交互终端

完整 PTY，进程还在

top、vim、htop 照常用。每条主机会话各有一条 shell，切回去 cwd 与运行中的进程都还在。TUI 定格帧可进模型上下文，但不落历史。

安全默认，而不是事后补丁

本机加密凭证库、主机指纹 TOFU、跨主机默认关闭、远端输出按不可信数据处理。你看到的是原文，模型看到的是脱敏后的内容。

  • 密码与私钥只进本机 vault，LLM 只能看到主机 ID
  • 硬拒绝破坏性命令与凭据路径；Agent 高危变更需人工批准
  • 审计日志加密落盘，带哈希链校验与导出
  • 附图仅当前轮：MIME + 魔数校验，不进历史与审计

三分钟跑起来

Go 1.26+、Node 18+、Wails CLI v2。Windows 也可用 scripts\build.bat 一键打包。

git clone https://github.com/3thinkthendoit/Ai-Shell.git
cd Ai-Shell
cd frontend && npm install && cd ..
wails dev
